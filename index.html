notdevelopers.dev

Тут коротко про те, що цей домен нам дає, скільки коштує і як ним користуватися.

Що дає

  • Захист через Cloudflare: IP сервера з API не видно ззовні, і атаки впираються в них, а не в нас.
  • Застосунок не зламається при переїзді на інший сервер: міняється один запис у DNS, а не адреса в коді.
  • HTTPS для сайтів і API без ручної роботи з сертифікатами.
  • Піддомен для свого: ім'я.notdevelopers.dev під власні проєкти чи як бажаєте.

Ціна

Перший рік безкоштовний (до 10 жовтня 2027). Далі $12,2 на рік, тобто приблизно 80 гривень з людини.

Питання

Як отримати піддомен?
Напишіть у групу, яке ім'я хочете і куди воно має вести: GitHub Pages, свій сервер чи щось інше. Запис додається за кілька хвилин.
Що можна там розмістити?
Резюме, власний чи командний проєкт, тестову версію чогось.
Що буде через рік?
Якщо домен нам потрібен, скидаємось на продовження. Якщо ні, він просто закінчиться.
А якщо хочемо іншу назву?
Скажіть. Поки адресу не зашито в застосунок, змінити її легко.
